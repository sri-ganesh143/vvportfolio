# Vengat Karthikeyan M — Portfolio

Plain HTML + CSS + JavaScript with a bundled Three.js 3D scene. No build step, no server needed.

## Files (single folder, no subfolders)
```
index.html   page content
style.css    styling
script.js    UI interactions
app.js       3D scene + skills constellation (Three.js bundled in)
resume.pdf   resume download
```

## Run
Just double-click `index.html` — it works offline (fonts need internet).

## Deploy
- **Vercel:** upload/deploy this folder (framework preset: Other). `index.html` must be at the root.
- **Netlify:** drag the folder onto app.netlify.com/drop.
- **GitHub Pages:** push these files to the repo root, then enable Pages.
